# NavMateへ取り込む風の値

## 確定した方針

2026-11-22のユーザー指定により、将来NavMateへこの資料の風を取り込む際は、
**紙面から手入力する場合と同じ丸め後の風向・風速**をNAVLOG計算に使用する。
風向は10度単位、北は360度。風速もその版の紙面に表示した値と一致させる。
紙面の対象日・予報対象時刻・版を特定し、同じセクターと高度の値を入力する。

丸め前の平均風は元データと検証のために保持する。計算に成分が必要な場合は、
選んだ紙面の風向・風速から成分へ変換し、内部に残した丸め前の成分へ戻さない。
この決定は風の入力に関するもので、気温、CAS/TAS、燃料の計算条件を追加で変更するものではない。

## リポジトリとデータの受け渡し

気象資料サービスとNavMateは別リポジトリを維持する。
気象資料サービスが画像と元データを同じ版として生成し、NavMateはその版を風の入力方法の一つとして取り込む。
使用した版と実際の入力値は計算結果と一緒に保存し、後日の資料更新によって過去の計算の使用風を変えない。

疑似セクターは表を選ぶための区画であり、値は対応する代表レグ全長の平均風である。
区画内の任意地点の風を示すデータとして扱わない。

## 今回の対象範囲

今回確定するのは入力値とリポジトリ分離の方針である。NavMateへの選択肢追加は将来の作業とし、
今回はNavMateのコードを変更しない。セクター選択の具体的なUI、対象外の高度・時刻・範囲の扱いなどは、
その機能を実装する時点で受入条件を決める。
