# 作業環境と後片付け

このサービスはGitHub Actions上のPython/NodeとCloudflare Pages/Workersで動作する。
NavMateのCompose、共有volume、worktree用ポートの設定は持ち込まない。

## 作業開始

作業checkout、branch、base commit、変更対象を確認する。既存の未コミット変更を識別し、
自分のタスクに必要な範囲だけを変更・stageする。既存NavMateやMSMの作業領域・本番設定は参照対象であり、
このサービスの設定先と混同しない。

## 開発用バックアップの保持条件

一時バックアップが必要なら、作成前に目的、正確な対象、破棄条件を非公開の作業記録へ残す。
復元に必要な範囲に限り、秘密情報をGitや公開文書へ入れない。
本番バックアップ・稼働データ・未完了作業は保護する。古さやサイズだけで削除を判断しない。

## 作業終了時の整理

自分が作成したcheckout、プロセス、キャッシュ、一時バックアップを確認する。
完了済みで所有関係と未コミット変更が確認できたものだけを整理する。
稼働中、未完了、所有者不明の環境は保持し、理由を記録する。
本番配信に必要な画像・JSONや、ユーザーが利用するファイルを一時物として削除しない。
global prune、他作業のプロセス終了、広範な再帰削除は行わない。
